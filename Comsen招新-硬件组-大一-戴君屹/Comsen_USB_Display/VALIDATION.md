## 接板后依次核对

每个独立算式前先按 AC，确保没有沿用上一个测试的输入；检查模式切换时按步骤指定单位和实数/复数模式。

1. 烧录 `firmware/comsen_usb_display.hex`，下载校验成功后复位。
2. 输入 `1+2`，按顶部 OK，应上行显示算式、下行显示 `3`。
3. AC 后输入 `1+2*3`，用原执行计算键确认，应为 `7`。
4. 输入 `12`，DEL 一次应为 `1`；清空后再 DEL 不应异常。
5. 按住数字键一秒应只输入一次，松开再按可再次输入。
6. 检查 `0..9`、小数点、`+ - * /` 与印字一致；`-3*2` 为 `-6`，`1/2` 为 `0.5`。
7. `1/0` 应为除零提示，`1+` 应为语法提示；错误后可删除或追加修正。
8. 满 16 字符再输入不得越界，DEL 后可以继续输入。
9. MODE 切换两片芯片原始位图，再按返回计算器。
10. USB 串口发送 `Hello` 显示电脑内容，按 AC 返回计算器，再发送可切回 USB。
11. 括号输入 `(1+2)*3` 应为 `9`；SHIFT 后按 1，再按 `3 0 ) OK`，角度制应显示 `sin(30)` 和 `0.5`。
12. SHIFT 后按 8 切换 RAD，再输入 `sin(pi/2)` 应为 `1`，AC 后角度单位不变。
13. 检查 `sqrt(9)=3`、`log(100)=2`、`ln(e)=1`、`2^3^2=512`，操作见 README 的 SHIFT 表。
14. `sqrt(-1)` 应为 `Math ERROR`，缺少右括号应为 `Syntax ERROR`，函数不能超出 16 格边界。
15. SHIFT → MODE 进入 CPLX 后，`sqrt(-1)` 应为 Re=0 / Im=1；切回实数应提示 Math ERROR。
16. SHIFT → 9 输入 i；检查 `(1+i)*(1-i)` 为 Re=2 / Im=0，`(1+i)/(1-i)` 为 Re=0 / Im=1，`i^2` 为 Re=-1 / Im=0。
17. 复数结果每部分 6 位有效数字、不会截断指数；AC 保留 CPLX 和角度单位，DEL 可回到原算式编辑。
