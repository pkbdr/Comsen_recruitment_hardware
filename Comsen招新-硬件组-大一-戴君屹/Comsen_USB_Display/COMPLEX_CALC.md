# 第六项：复数扩展

本功能由 AI 按使用者授权实现，使用 `basic_calc.c` 的统一定长解析器和 `complex_math.c`
的实数/复数数学后端，没有链接原仓库的计算库。原实数接口与定义域行为保留。

## 按键与显示

- 单击并松开 SHIFT，再按 9：输入 `i`，自动进入 CPLX 复数模式。
- SHIFT → MODE：切换实数/复数。单独 MODE 仍为原始按键测试，不会混淆。
- SHIFT → 8：DEG/RAD。AC 保留角度和实数/复数模式，复位后默认实数 DEG。
- 支持 `i`、`-i`、`2i`、`.5i`，系数与 i 紧邻；一般乘法仍需 `*`。
- 运算符、括号和第五项 SHIFT 函数沿用原按法。算式仍最多 16 字符。
- 复数模式的结果占两行，`Re=` 与 `Im=` 分别标出实部和虚部，每部分 6 位有效数字。
- 错误时上行保留算式，下行显示提示。DEL 删除原算式末尾后返回编辑；AC 清空输入和结果。
- 成功计算后数字、函数或 i 开始新算式，运算符继续编辑原算式；不提供以历史结果为首操作数的自动链式计算。

## 运算范围

- 四则、括号、整数和一般复数乘方；乘方从右向左结合。
- `sqrt`、`ln`、`log`、`sin`、`cos`、`tan` 支持复数。
- 对数、平方根和一般复数乘方使用主值；负实轴且虚部恰为零时采用上侧分支，
  因而 `sqrt(-1)=i`、`ln(-1)=πi`。正负零统一显示为 0。
- DEG/RAD 对三角函数的整个复数输入进行单位转换。复对数的虚部始终是弧度相位，
  不受 DEG/RAD 影响；复数乘方同样使用自然复对数的弧度相位。
- `0^0`、零的非实数次幂、`ln(0)`、`log(0)` 为数学错误；除零和零的负实数次幂为除零错误。
- 非有限或可检测的乘方/复数乘除下溢结果为范围错误；浮点舍入误差仍然存在。
- 使用 double 计算，无动态内存。复数乘除对部分极大/极小数采用归一化处理，
  整数次幂采用平方乘法，避免为很大的整数指数执行线性次数循环。

## 例子

| 输入与模式 | 结果 |
| --- | --- |
| `(1+i)*(1-i)`，CPLX | Re=2，Im=0 |
| `(1+i)/(1-i)`，CPLX | Re=0，Im=1 |
| `i^2`，CPLX | Re=-1，Im=0 |
| `sqrt(-1)`，CPLX | Re=0，Im=1 |
| `sqrt(-1)`，实数 | Math ERROR |
| `sqrt(3-4i)`，CPLX | Re=2，Im=-1 |
| `sin(i)`，CPLX RAD | Re=0，Im≈1.1752 |
| `1/(i-i)`，CPLX | Divide by zero |

## 接口与测试

```c
basic_calc_complex_t value;
basic_calc_status_t status = basic_calc_evaluate_complex(input, input_len,
                                                        BASIC_CALC_RAD, &value);
```

输入可以不带结束符，长度必须为实际字节数且不超过 16；失败时 value 不会被改写。
`basic_calc_render_complex` 直接输出两行定长字符数组；输出数组各需 16 字节，不带 `\0`。

运行 `tests/run_native.ps1` 会检查原有功能、复数测试、独立 Python cmath 参考算式和输出边界。
这不代替实板接线、按键感应、实际 LCD 效果及烧录验证；最新整合版已烧录；使用者已确认 CPLX 模式下 sqrt(-1) 显示 Re=0 / Im=1、i^2 显示 Re=-1 / Im=0。其他复数算式和边界未逐项实板复验。
